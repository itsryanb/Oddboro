- [meta] **Decision (2026-11-13): the smoke tests run before a release, not only in it.** Every pull request runs the staged server's smoke test in Checks on a Mac, Linux and Windows. Every pull request that changes what goes into the app (`apps/desktop`, `apps/office`, `packages`, `.nvmrc`) also builds the app unsigned on Windows, macOS 15 and Ubuntu 22.04 and runs the installed-app smoke test on each, and every night `main` does the same on all six machines the release tests on. A change to the office can break only the installed app, as Revoke did in 0.0.5 (#25), so a filter on `apps/desktop` alone would miss it. The pull request run does not block a merge until its failures are known to be real, then becomes required. The steps are in `.github/workflows/ci.yml` and `app-smoke.yml`; what each row checks is in `apps/desktop/CLAUDE.md`, "Smoke tests".
